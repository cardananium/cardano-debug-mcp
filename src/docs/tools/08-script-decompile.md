# script_decompile

- The decompiler's `// Info` / `// Warning` / `// Note` lines come first and as `notes[]`: what is exact and what is guessed (church-bool polarity, V1/V2 ambiguity, unknown purpose).
- Pseudocode is heuristic (synthesised names; `Constr<N>` / `.tag` are not real Aiken); `view='uplc'` is the exact program for confirming a doubtful branch. Every view has its own layout and names: no view's line numbers are debugger positions (debug-playbook/correlating-pseudocode).
- `plutus_version`: V1 vs V2 changes TxInfo field names, and the UPLC header alone cannot tell them apart. `purpose` changes the validator wrapper and argument names; V1/V2 non-spend purposes are indistinguishable from bytecode.
- `options` (pseudocode only; defaults = the de-uplc-web preset): `strip_all_traces` drops every trace from the rendering (log-dropping: the compiled script still emits them); `strip_plutustx_traces` only PlutusTx's per-call enter/exit pairs; `decode_church_to_native` (default true) rewrites Church-encoded pairs / booleans to native forms marked `// church-…`; `expect_or_fail` (default true) renders single-branch matches as `expect P = X or fail @"msg"` keeping the message (not real Aiken); `synthesize_stub_adts` (default false) emits `pub type Unknown_S_<n>` declarations instead of raw `Constr<tag>`; `safe_mode` skips the aggressive recovery / polish passes (more literal, less normalised: try it when the default rendering looks wrong); `compilable_data_access` (default false) writes the Data-access spine as `builtin.un_constr_data(x).2nd` instead of `x.fields`; `split_purposes` is the V3 multi-purpose dispatch; `applied_kind` says how outer Apply nodes are read (`compile` = parameters compiled in); `raw` passes any other dehosk option by its catalogue path (e.g. `{"readability_passes": {"rename_variables": false}}`), validated against the option catalogue.
- The full text is cached per (script, options), so paging is free, and is readable as a resource. Identical parallel requests share one run; a script the decompiler gave up on is refused for a while (`refresh=true` retries).
- `dbg_id` reads the bytes the session was opened from: a session opened from UPLC text has none (`no_script_bytes`), so pass the compiled script via `script`.
